# Phase 30 - Proposed Research Roadmap

Status: proposal only; not approved.

1. Establish versioned benchmarks for instruction following, mathematics,
   programming, cybersecurity, English conversation and multimodal tasks.
2. Record dataset licensing, provenance, splits, evaluation scripts and
   baseline model hashes.
3. Measure accuracy, calibration, latency, memory use and failure categories.
4. Repeat controlled experiments and report variability.
5. Separate hypotheses from validated findings.
6. Require reproducibility review and explicit approval before roadmap changes.

This proposal makes no claim that a model capability has improved.
